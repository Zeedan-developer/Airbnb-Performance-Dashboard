# Global Airbnb Performance Dashboard | Power BI

## Project Overview

Developed an interactive **Global Airbnb Performance Dashboard using Microsoft Power BI** to analyze listing performance, host information, customer ratings, and review patterns across 10 cities.

The project transforms Airbnb listing and review data into meaningful visual insights using interactive charts, KPI cards, conditional formatting, and DAX measures. It helps users understand market distribution, property performance, customer satisfaction, and host trust indicators.

## Key Features

### 1. Overview Dashboard
- Displays key performance indicators: 279,712 listings, 10 cities, 182,024 hosts, 144 property types, and approximately 5.37 million reviews.
- Analyzes listing growth across different years.
- Compares Entire Place, Private Room, Hotel Room, and Shared Room listings.
- Highlights major growth periods and changes in listing trends.

### 2. Ratings Dashboard
- Analyzes market share across cities.
- Compares Superhost and non-Superhost listings.
- Visualizes cumulative market share.
- Compares average prices across property types.
- Uses a conditional-formatting matrix to compare city-level ratings for accuracy, cleanliness, communication, location, and value.

### 3. Reviews Dashboard
- Analyzes reviewer activity and review frequency.
- Examines the distribution of reviews per reviewer.
- Uses cumulative reviewer frequency to understand customer review behavior.
- Evaluates host identity verification and profile-photo status to explore trust-related indicators.

## Tools and Technologies

- **Microsoft Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data transformation and preparation, where applicable
- **DAX (Data Analysis Expressions)** — Measures, calculations, and percentage-based analysis
- **Data Visualization** — KPI cards, line charts, combo charts, matrix visuals, and conditional formatting

## Key Analytical Takeaways

- The dataset covers 10 cities and multiple property categories, enabling comparisons across different Airbnb markets.
- Listing trends reveal periods of growth, maturity, and decline.
- City-level analysis helps compare listing concentration, Superhost presence, and property prices.
- Review-frequency analysis helps identify patterns in customer reviewing behavior.
- Host verification and profile information provide additional dimensions for exploring trust and credibility.
